================================================================================
COMO USAR
================================================================================

1. PREVISÃO ANUAL
   - Acesse a aba "Previsão Anual"
   - Preencha os valores previstos
   - Clique em "Salvar Previsão"

2. ACOMPANHAMENTO MENSAL
   - Clique no botão do mês desejado
   - Edite os valores reais
   - Marque ✓ para confirmar
   - Clique em "Salvar Dados do Mês"

3. CARTÕES DE CRÉDITO
   - Adicione itens com descrição e parcelas
   - Informe valor mensal e falta
   - Marque ✓ para confirmar

================================================================================
DEPLOY NO NETLIFY
================================================================================

OPÇÃO 1: DRAG & DROP (Mais Fácil)
   1. Acesse https://app.netlify.com/drop
   2. Arraste a pasta /simplesfinanceiro
   3. Pronto! Site está online

OPÇÃO 2: GITHUB + NETLIFY (Recomendado)
   1. Faça push para GitHub
   2. Conecte no Netlify
   3. Deploy automático a cada commit

OPÇÃO 3: CLI
   1. npm install -g netlify-cli
   2. netlify login
   3. netlify deploy --prod

Veja DEPLOY_GUIDE.md para instruções detalhadas!

================================================================================
SUPORTE E TROUBLESHOOTING
================================================================================

PROBLEMA: Service Worker não registra
SOLUÇÃO: Verifique se está em HTTPS, limpe cache

PROBLEMA: Ícone não aparece
SOLUÇÃO: Verifique se arquivos estão em icons/, limpe cache

PROBLEMA: Dados não salvam
SOLUÇÃO: Verifique se LocalStorage está habilitado

PROBLEMA: PWA não instala
SOLUÇÃO: Verifique se está em HTTPS, aguarde alguns segundos

Veja README.md para mais detalhes!
